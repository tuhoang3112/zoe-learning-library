## 4. Behavior on the page (Clarity) — decision recorded

Microsoft Clarity (heatmaps, session recordings) was **not installed**. Reasons: traffic to the Library is still small, so recordings would be few; GA4 events already answer the main behavioral questions (what is clicked, what is searched, where visitors leave). It can be added later through Tag Manager without changing code. It cannot run on Substack at all (non-Google tags are blocked, see [`tracking-audit.md`](tracking-audit.md)).

## 5. GEO / AI search citation check — protocol

Question: are the posts and the Library cited by AI search tools, and which ones are not?

**Procedure**
1. Fix a list of 20 queries: brand queries ("Zoe's Data & AI Lens", "Zoe's Learning Library") and topical queries matching the main series (SQL for beginners, GA4 and GTM, n8n automation, Power BI, learning AI from zero), in English and Vietnamese.
2. Run each query in ChatGPT (with search), Perplexity and Google (AI Overview), in a fresh session and logged out where possible.
3. Record whether my site or a Substack post is cited, which URL, and the position among the sources.
4. Repeat monthly with the same list so results are comparable.
